About the project

This project detects phishing URLs using 30 URL, domain, and page features with a trained machine-learning model.

Feature extraction
URL length, HTTPS, subdomains, anchors, redirects, and domain age.
Prediction
A saved classifier produces phishing and legitimate probabilities.
Interface
Flask routes provide signup, login, URL search, and results pages.
