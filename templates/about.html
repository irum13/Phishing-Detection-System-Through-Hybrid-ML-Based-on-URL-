Project overview

Hybrid machine learning for URL phishing detection.

This project turns a raw URL into model-ready features, predicts risk, and presents the result through a Flask frontend.

Feature extractionMeasures URL length, HTTPS use, special symbols, subdomains, anchors, redirects, domain age, page links, and more.
Prediction modelLoads a saved classifier from model.pkl and returns safe and phishing probability scores.
Web workflowIncludes a home page, URL checker, results page, notebook links, signup, and login screens.
